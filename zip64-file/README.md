# zip64-file

ZIP 64 file handler for reading and writing large ZIP archives.

## Module Overview

This module provides ZIP 64 format support for:
- Reading and writing ZIP files with 64-bit extensions
- Handling archives larger than 4GB
- Command-line tools for ZIP operations
- SIARD archive compression and decompression

## Building and Testing

**Build this module:**
```shell
./gradlew :zip64-file:build
```

**Run tests:**
```shell
./gradlew :zip64-file:test
```
