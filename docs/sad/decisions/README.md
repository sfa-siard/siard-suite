# Architecture Decision Records (ADRs)

This directory records significant architectural decisions for SIARD Suite.

## Format

Records follow a lightweight MADR-like structure:

- **Title** and status
- **Context** — the forces and constraints that require a decision
- **Decision** — what we decided
- **Consequences** — positive, negative, and neutral outcomes
- **Alternatives** — options considered and why they were rejected

## Status values

- **Proposed** — under discussion
- **Accepted** — agreed and in effect
- **Deprecated** — superseded by a later decision
- **Superseded by ADR-XXXX** — replaced with a reference to the new ADR
